# TSIA2 English and Math practice

Open the hosted page after Pages is enabled:

https://sklolzhelp.github.io/tsia2-practice/

`index.html` is a single file at the root of `main`. It includes the questions, grading, and browser resume memory.

This is original TSIA2-style practice, not an official College Board test, and it does not produce a CRC score.

## Turn on hosting

The GitHub connection used to push this repo cannot change Pages settings. One click on the account does it:

1. Open https://github.com/sklolzhelp/tsia2-practice/settings/pages
2. Build and deployment: Deploy from a branch
3. Branch: `main`, folder: `/ (root)`
4. Save

The site URL is https://sklolzhelp.github.io/tsia2-practice/

## What it does

- English (ELAR) and Mathematics, alone or together
- Full sample (20 + 20) or 5, 10, or 15 questions
- Resume an unfinished attempt in the same browser
- Grade by category, with missed items and practice links

Official readiness routes are still Math CRC 950–990, or below 950 plus Diagnostic Level 6; ELAR CRC 945–990 plus essay 5–8, or below 945 plus Diagnostic Level 5 or 6 and essay 5–8.

Official sample PDFs: https://accuplacer.collegeboard.org/students/tsia2-additional-resources
