# TSIA2 English and Math practice

Original multiple-choice practice for the Texas Success Initiative Assessment 2.0 content categories. This is not an official College Board, ACCUPLACER, or Texas Higher Education Coordinating Board test, and it does not produce a CRC score.

Open `index.html` in a browser, or serve this folder and enable GitHub Pages from the repository root.

## What it does

- English (ELAR) and Mathematics sections, alone or together
- Full sample (20 English + 20 Math) or 5, 10, or 15 questions
- Browser memory through `localStorage`, so an unfinished attempt can be resumed on the same device
- End-of-test grade by category, with the missed items and a practice link for weak areas
- Answer key written into each item and checked by `scripts/verify_questions.py`

## Scoring note

Official statewide routes, confirmed on Texas college testing pages:

- Mathematics: CRC 950–990, or CRC below 950 plus Diagnostic Level 6
- ELAR: CRC 945–990 plus essay 5–8, or CRC below 945 plus Diagnostic Level 5 or 6 and essay 5–8

A raw percent on this sample cannot be converted into those scaled scores. The real multiple-choice sections are untimed and adaptive. The essay (WritePlacer) is not included here.
